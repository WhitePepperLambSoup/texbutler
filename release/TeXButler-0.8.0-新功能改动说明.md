# TeXButler 0.8.0 新功能与改动说明

- 版本：`0.8.0`
- 功能代码范围：`5b36ddc..ac86074`（9 笔界面重构、功能、修复与文档提交）
- 当前分支：`main`
- 说明日期：2026-10-05

## 重点更新

### 1. 文件管理

- 项目树新增右键菜单：文件夹可"在此新建文件 / 新建文件夹"，文件可打开、分屏打开、设为主文件、查看历史；均可重命名、移动、复制相对路径、在资源管理器中显示和删除。
- 支持拖放移动文件和文件夹，拖到项目根目录空白处即移回根目录。
- 删除不直接抹除文件，而是移入项目内回收站（`.texbutler/trash/`），提示中可一键"撤销"恢复。
- 重命名或移动后，已打开的标签、主文件设置和分屏文件同步更新；移动前自动保存未保存的修改。
- 路径统一校验：拒绝 `..` 越界、`.texbutler` / `.git` 内部目录和非法字符。
- 在资源管理器、git 或其他程序中新建、删除、重命名的文件会实时出现在项目树中（此前需重新打开项目）。

### 2. 全项目搜索与替换

- 侧栏新增"搜索"页，快捷键 Ctrl+Shift+F，以编辑器选中文字为初始查询。
- 支持区分大小写、全词匹配和正则表达式；结果按文件分组，点击直接跳转到对应行列。
- 支持单文件替换和全部替换，替换前确认数量；替换前自动为每个受影响文件留存历史版本。

### 3. 内置 PDF 阅读器（pdf.js）

- 取代 WebView2 自带的 PDF 查看器：重新编译后保持当前页面和滚动位置，不再跳回第一页。
- 页面按需渲染，支持缩放、Ctrl+滚轮、适应宽度、页码跳转、夜间反色和文字选择。
- 正向定位（编辑器 → PDF）会滚动到对应位置并高亮该行；双击 PDF 任意位置反向跳回源码行（内置 SyncTeX 解析，无需系统 synctex 命令）。
- 工具栏新增"PDF 另存为"和"打开输出文件夹"。
- CJK 字形映射、标准字体和解码器随应用打包，离线可用。

### 4. 本地文件历史

- 保存、全局替换和恢复前自动留存版本（同一文件最多每 2 分钟一个，保留最近 50 个），存放在 `.texbutler/history/`。
- 历史窗口列出各版本，显示与当前内容的行级差异（折叠未改动部分），一键恢复；恢复前会先保存当前状态，因此恢复本身也可撤销。

### 5. Git 状态

- 项目树显示修改（M）、新增（A）、未跟踪（U）、删除、冲突等标记，文件夹内有改动时显示圆点。
- 状态栏显示当前分支、领先 / 落后提交数和改动文件数。
- `.texbutler/` 内的编译产物、备份与历史不再计入改动，并自动写入 `.texbutler/.gitignore`。

### 6. 引用、文献与大纲

- 大纲改为"本文件 / 全文档 / 标签"三种视图；全文档视图跟随 `\input` / `\include` 列出所有章节。
- 标签视图：未定义引用、重复标签、未被引用的标签，以及每个标签的引用次数，可一键插入 `\ref`。
- 文献面板：每条文献的引用次数、正文中缺失的 `\cite` 键，以及"只看未引用"筛选。

### 7. 拼写检查与编辑器偏好

- 离线英文拼写检查（Hunspell 词典）：只检查正文，跳过命令名、数学、注释、标签键、浮动体位置参数和 `\hypersetup` 等设置项，以及中文、含数字和全大写缩写。
- 快速修复提供拼写建议，并可"添加到词典"（个人词典本地保存）。
- 编辑器偏好：字体、字号（Ctrl+= / Ctrl+- / Ctrl+0）、自动换行、行号、小地图、缩进宽度、拼写检查开关。

### 8. 编译引擎与应用更新

- 没有可用编译引擎时，PDF 区域和引擎窗口给出说明；一键下载安装 Tectonic 0.15.0 到用户目录并校验 SHA-256，或前往 MiKTeX / TeX Live 下载页。
- 应用内更新：检测到新版本后显示更新说明，下载安装包并显示进度，下载完成后一键安装。下载地址仅允许本项目 GitHub Releases 的安装包，并校验文件大小；只运行由更新程序下载的安装包。

### 9. AI

- 问题面板新增"AI 修复全部"：逐个修复编译错误并重新编译，直到通过或无法继续，过程记录在 AI 对话中。
- 公式窗口新增"图片转公式"：选择截图后由 AI 识别为 LaTeX 公式；模型不支持图片输入时给出明确提示。

### 10. 界面：Apple 风格与 Liquid Glass

- 参照 Apple 人机界面指南重做全部界面：系统字体、systemBlue 强调色与层级化文字颜色；macOS 风格的按钮、菜单（强调色高亮）、分段控件、开关、输入框和表单。
- 设置改为"系统设置"式布局：左侧带彩色图标的分区，右侧分组圆角列表。
- 命令面板仿 Spotlight，提示仿通知中心，对话框改为居中标题的面板。
- 液态玻璃升级为 Liquid Glass：面板（包括编辑器）半透明透出背景，镜面高光描边、顶部光泽、胶囊形玻璃控件，背景光斑更鲜明；大面积区域不使用背景模糊，避免 WebView2 闪烁。

## 端到端测试中发现并修复的问题

- **Tectonic 从未真正运行**：编译时没有使用已找到的 Tectonic 路径，而是到 PATH 查找，总是静默回退到系统 TeX；同时将找到的相对路径改为绝对路径。
- Tectonic 编译错误被定位到字体文件（如 `ts1cmr.fd`）而非源文件，现改用 Tectonic 输出中的精确位置；Tectonic 与系统 TeX 都失败时同一错误不再显示两遍。
- 外部新建、删除、重命名的文件不出现在项目树中。
- "移动到…"无法移到项目根目录（空输入被拒绝）；首次编译前"打开输出文件夹"报错；路径混用斜杠时资源管理器定位失败。
- 拼写词典导入在 Vite 冷启动时无法解析，导致开发环境页面空白。
- 英文界面编译过程中，状态栏显示中文进度文案（后端文案未按界面语言转换）。
- 编辑器获得焦点时出现蓝色描边。
- 此前的界面重构阶段还修复了：编辑器自 v0.4.0 起缺失补全、悬停预览、查找替换、折叠和右键菜单；AI 回滚在 Windows 上总是失败；长路径项目编译错误无法定位；外部修改被静默覆盖；分屏编辑改成 CRLF；多编辑器快捷键串扰等问题（详见 CHANGELOG）。
