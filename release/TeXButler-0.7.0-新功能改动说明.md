# TeXButler 0.7.0 新功能与改动说明

- 版本：`0.7.0`
- 本轮功能源提交：`2060b422103fa78f9549d868fbbdad1409f32ae1`
- 合并分支：`codex/fix-ui-ai-layout` → `main`
- 说明日期：2026-08-10

## 重点更新

### 1. AI 对话工作区重新设计

- 重新整理 AI 面板的消息区、输入区、工具栏和操作菜单布局，解决控件错位、遮挡、间距失衡及视觉层级混乱的问题。
- 每个打开的 TeX 文件拥有独立 AI 对话；切换或打开新文件时自动进入该文件对应的对话，已有文件对话不会被关闭。
- 文件级 AI 对话会持久化保存，软件退出并再次打开项目后仍可恢复。
- AI 会话按项目与文件路径隔离，避免同名文件或跨项目切换时串用上下文。
- 改进 AI 修复流程的文件定位：工具可识别当前项目中的相对路径、绝对路径以及日志中带项目目录的路径，不再把 `read_file` 当作未知工具而直接终止修复。
- 修复快速切换项目时异步 AI、编译及文件刷新结果覆盖当前项目状态的问题。

### 2. 新建文件与模板流程

- 恢复并明确“新建文件”入口：文件始终创建在当前打开目录中，无需重复填写完整文件路径。
- 模板市场用于创建新文件，不再错误地强制进入“新建项目”流程。
- 新建文件对话框支持文件名、扩展名、模板选择和目标目录提示，并对无效名称及路径进行校验。
- 新建文件后自动打开编辑器，并自动建立该文件对应的 AI 对话。

### 3. UI 布局、外观与可读性

- 修复主界面多个区域的遮挡、挤压和尺寸计算问题，优化窄窗口下的布局表现。
- 修复“调整外观”和液态玻璃设置栏无法点击的问题。
- 降低“更多编辑工具”和“更多 AI 操作”弹层的透明度，增强背景分离度。
- 调整浅色、深色及玻璃效果下的文字、图标、边框和背景对比度，解决文字颜色与背景过近导致看不清的问题。
- 优化菜单、弹层、按钮、输入框、空状态和错误提示的视觉一致性。

### 4. 面板拖动体验

- 修复拖动分隔条后鼠标仍被捕获的“粘连”问题；松开鼠标、指针取消或窗口失焦时均会可靠结束拖动。
- 统一水平与垂直分隔条的尺寸计算，修复面板调整方向与鼠标移动方向相反的问题。
- 增加尺寸边界保护，避免拖动后侧栏、编辑器、AI 面板或 PDF 预览被压缩到不可用状态。

### 5. PDF 预览恢复

- 恢复 PDF 预览面板及相关布局状态。
- 修复面板切换、项目切换和重新编译后 PDF 区域消失或被其他区域覆盖的问题。
- 保留编辑器、PDF 与 AI 面板之间的可调布局能力。

### 6. 编译与项目状态可靠性

- 为项目和文档路径增加统一规范化处理，减少 Windows 路径、相对路径和日志路径不一致造成的文件读取失败。
- 修复跨项目编译、刷新和异步响应返回顺序不一致时，旧项目结果覆盖新项目的问题。
- 改进项目树、新建文件、编译结果与 AI 当前文件之间的同步。
